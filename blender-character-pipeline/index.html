THE BIG PICTURE

先看全局：角色资产是几种数据的组合

3D 角色不仅仅是一个好看的外壳。一个能在 Unity 里眨眼、转头、挥手的桌宠，还必须拥有形状数据、表面描述、变形规则和动作数据。点击任意节点可跳回上方对应观察站。

ROUTE A · STYLIZED / GAME-READY

直接低模 / 中模建模

从球体、立方体或已有 Base Mesh 开始，直接建立适合绑定和动画的网格。适合风格化、较简洁、需要控制面数的人物。省掉高模雕刻并不意味着省掉拓扑设计。

ROUTE B · HIGH DETAIL

MENTAL MODEL

六个最容易混淆的概念

Mesh ≠ 外观贴图

Mesh 的点、边和面决定空间形状。材质与纹理负责颜色、反光、细节等表面外观。贴图无法自动修复错误轮廓。

Topology ≠ 面数越少越好

重点是关节附近的边流与变形质量。过少会塌陷；过密会增加成本。四边面便于编辑，渲染时通常三角化。

UV ≠ 材质

UV 是 3D 表面到 2D 图像的坐标映射。你可以没有贴图使用纯色材质；但使用常规二维图像纹理通常需要 UV。

骨骼 ≠ 权重

骨骼是变换控制结构；权重决定每个顶点受哪些骨骼影响、影响多少。自动权重只是起点。

Shape Key ≠ 骨骼

Shape Key 存储顶点位移，适合嘴型与表情；骨骼更适合四肢和躯干运动。角色可以同时使用两者。

GLB ≠ VRM

GLB 是通用 glTF 二进制封装；VRM 在 glTF 基础上规定人形角色规范与扩展。导出 GLB 不代表自动拥有可用的 VRM 表情、Humanoid 信息。
